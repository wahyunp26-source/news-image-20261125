# Font licences

The glyph atlases in `assets_blob.py` were rendered at build time from
system fonts. No font files are shipped in this repository.

- **Liberation Serif** (Regular, Bold, Italic) — `LiberationSerif-Regular.ttf`,
  `LiberationSerif-Bold.ttf`, `LiberationSerif-Italic.ttf`
- **Liberation Sans** (Regular, Bold) — `LiberationSans-Regular.ttf`,
  `LiberationSans-Bold.ttf`
